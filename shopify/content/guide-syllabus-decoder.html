Fill in one copy per course

This is the part worth knowing before you start: every page is about a single class. Download it once, then save a separate copy for each course you're taking — name them something like Decoder – BIO 101 — and work through each one with that syllabus open beside you. One copy split across five classes turns into a mess you'll have to redo.

How to open and fill it in

Tap the button and the PDF opens in a new tab. Save it to your device first, then fill it in from the saved copy — answers typed into a preview window are easy to lose before they're written to the file.

  • iPhone or iPad: tap the share icon and choose Save to Files. Open it from the Files app, tap any blank line, and type. To make a copy per course, press and hold the file and choose Duplicate.
  • Android: the file saves to Downloads. Open it with Drive PDF Viewer or Adobe Acrobat Reader, tap a blank line, and type. Use Make a copy for each course.
  • Mac: it opens in Preview. Click a blank line, type, then File → Save. Use File → Duplicate for each course.
  • Windows: it opens in Microsoft Edge or Acrobat Reader. Click a blank line, type, then Save as — a new name per course.

The checkboxes and the grids work the same way — click or tap a box to tick it, tap a cell to type in it. Save as you go; ten pages is a lot to lose.

Rather do it on paper? Print it blank, once per class, and fill it in by hand. It's built to work either way.

Do this in the first week, while the syllabus is still new and nothing is due yet. That's the whole trick — the information was always there: the weighting, the drop policy, the office hours. It's just written in a way nobody reads twice. An hour with this now is the difference between finding out in week two that participation is 20% of your grade and finding out in week twelve.
